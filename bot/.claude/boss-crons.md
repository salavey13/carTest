# Boss Cron Jobs (auto-renewed)

> Source of truth для boss-mode recurring jobs.
> Renewal-cron (`33 3 */6 * *`) читает этот файл и пересоздаёт все 4 джобы каждые 6 дней — обходит хард-лимит CronCreate в 7 дней.

## How to renew (инструкция для renewal-джобы)

1. Прочитай этот файл целиком (до конца).
2. `CronList` — найди все cron IDs, чей `prompt` начинается с маркера `[BOSS]`.
3. Для каждого — `CronDelete`.
4. Для каждой джобы из секции **Jobs** ниже — `CronCreate` с параметрами:
   - `cron`: из карточки джобы
   - `recurring: true`
   - `durable: true`
   - `prompt`: точный текст из карточки (включая маркер `[BOSS]`)
5. `CronList` — проверь, что создано **4** crona с маркером `[BOSS]`.
6. Скажи пользователю кратко: «🔄 Boss crons renewed (4 jobs). Next renewal ~6 дней.»
7. Если что-то упало — скажи сразу, какая джоба не пересоздалась (остальные всё равно должны быть созданы).

**Важно:** промпты — byte-identical. Не сокращай, не перефразируй. Внутри промптов лежат триггеры для skill `vip-bike-ops` и ссылка на этот файл (для renewal).

**Доставка сводок (A/B/C):** финальный шаг каждого брифинга — `bash /opt/claudeclaw/vip-bike/scripts/broadcast.sh "<текст>"` (рассылает всем chat_id из `ALLOWED_CHAT_ID`: `6266482385,356282674,244736261,413553377,7813830016` = вся команда VIP Bike + групповой). В REPL-ответе — только подтверждение «отправлено N/M», сам текст сводки НЕ дублировать.

**Часовой пояс:** VPS на UTC. Cron-выражения ниже — в **UTC**. Чтобы получить MSK, вычитай 3 часа из целевого MSK-времени. Например вечерний отчёт 20:17 MSK = `17 17 * * *` (17:17 UTC). Не наоборот.

**Принудительное использование навыков (главное правило A/B/C):** каждый блок сводки требует явного вызова `Skill(skill="<name>")`. Без вызова навыка данные по блоку **запрещено выдумывать** — писать «нет данных». Нагенерить «Продаж: 0» без вызова `sale-analytics-text` = баг. Нагенерить цифры аренд без `rental-analytics-text` = баг. Нагенерить лидов без `leads-crm-text` = баг.

## Jobs

### A) Morning briefing — `7 6 * * *` (09:07 MSK = 06:07 UTC)

**Prompt:**

```
[BOSS] ☀️ Утренний брифинг (auto-cron, 09:07 MSK / 06:07 UTC).

⛔ ЖЁСТКОЕ ПРАВИЛО: каждый блок ниже требует ЯВНОГО вызова Skill(). Без вызова навыка — данные НЕ выдумывать, писать «нет данных». Цифры/имена/статусы «из головы» = баг.

ШАГ 0 (сначала, обязательно): вызови `Skill(skill="vip-bike-ops")` — это загрузит контекст.

Затем по блокам — для каждого ОБЯЗАТЕЛЬНЫЙ Skill():

1. **Аренды на сегодня** → `Skill(skill="rental-analytics-text")`
   Команда: «аренды сегодня». Сколько активных, кто первый клиент, что выдать.

2. **Возвраты сегодня** → `Skill(skill="rental-analytics-text")`
   Команда: «возвраты сегодня». Список, время возврата.

3. **Лиды в работе** → `Skill(skill="leads-crm-text")`
   Команда: «горячие лиды». Кто ждёт ответа, у кого скоринг высокий.

4. **Crew todos на сегодня** → `Skill(skill="crew-admin-text")`
   Команда: «задачи на сегодня». Что в очереди у команды.

5. **Погода** → `Bash`: curl -sS "https://api.open-meteo.com/v1/forecast?latitude=56.2954&longitude=43.9446&daily=temperature_2m_max,temperature_2m_min,precipitation_sum,windspeed_10m_max&timezone=Europe/Moscow&forecast_days=1" | jq -r '.daily'
   Только если осадки > 5мм или ветер > 30 км/ч — влияет на прокат.

🔍 ПРЕД-ОТПРАВКОЙ (самопроверка): перечисли какие навыки были вызваны. Если хотя бы один из обязательных (vip-bike-ops, rental-analytics-text, leads-crm-text, crew-admin-text) не вызван — ВЕРНИСЬ и вызови, иначе данные не валидны.

Формат итога: кратко, цифрами, с эмодзи-маркерами секций. Без воды.
В конце — топ-3 приоритета на день.

Если данных нет (навык вернул пусто) — пиши «нет данных», не выдумывай.

**ФИНАЛЬНЫЙ ШАГ (доставка):** весь готовый текст сводки отправь команде через
`bash /opt/claudeclaw/vip-bike/scripts/broadcast.sh "<ТЕКСТ_СВОДКИ>"`.
Текст передав одним аргументом (экранируй кавычки внутри). После отправки —
в чат REPL выведи только одну строку: «☀️ Брифинг отправлен команде: ok=N/M (fail: <список chat_id через запятую>)».
Сам текст сводки в REPL НЕ дублируй.
```

Формат итога: кратко, цифрами, с эмодзи-маркерами секций. Без воды.
В конце — 1–2 строки «что важно на завтра».

Если по блоку данных нет (навык вернул пусто) — пиши «нет данных», не выдумывай.

**ФИНАЛЬНЫЙ ШАГ (доставка):** весь готовый текст сводки отправь команде через

После отправки — в чат REPL выведи только одну строку:
«🗓 Вечерний отчёт отправлен команде: ok=N/M (fail: <список chat_id>)».
Сам текст сводки в REPL НЕ дублируй.
