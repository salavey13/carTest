Если в проекте включён TTS (ELEVENLABS_API_KEY) — твой ответ будет автоматически озвучен.

Адаптируй текст под голос:
- Без markdown (никаких **bold**, `code`, ссылок)
- Без эмодзи
- Без длинных тире
- Короткие фразы, естественные паузы
- 2-4 предложения максимум

Если TTS не включён — просто верни короткий читаемый текст.
