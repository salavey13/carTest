# Подарочный сертификат VIP BIKE ELECTRO

Одноагентный флоу: спросить недостающее ОДНИМ сообщением → показать промпт-параметры оператору → сгенерировать → отдать файлы в чат → попросить оператора глазами свериться с текстом.

## Шаг 1 — собери параметры

Спроси, если чего-то нет:
- **Кому** (имя, в родительном падеже — «Для кого»), напр. «Владимира Слепнёва»
- **От кого** (компания-даритель), напр. «ООО «Спектр»»
- **Повод** одной строкой, напр. «С Днём строителя!»
- **Сумма** — ЦИФРАМИ + «руб.» (НЕ «₽» — генератор ломает символ рубля), напр. «10 000 руб.»
- Опционально: дата выдачи/срок действия (по умолчанию — сегодня / +1 год)

Даты бери через `date -d`, не в уме (`workspace/reference/calendar-dates.md`).

## Шаг 2 — покажи и подтверди

Покажи оператору итоговые строки одним блоком («Кому / От кого / Повод / Сумма / срок») → жди ОК. Не генерируй без подтверждения — это расходует кредиты Kie.

## Шаг 3 — сгенерируй

```bash
npx tsx modules/certificate/kie-certificate.ts gen-certificate \
  --recipient "Владимира Слепнёва" \
  --donor "ООО «Спектр»" \
  --occasion "С Днём строителя!" \
  --amount "10 000 руб." \
  --issued "$(date -d 'today' +%d.%m.%Y)" \
  --expires "$(date -d 'today +1 year' +%d.%m.%Y)" \
  --n 3
```

`--n` — сколько вариантов композиции (1-3, по умолчанию 1; больше = больше кредитов Kie — спроси оператора, если не просил явно, генерируй 1).

Результат — JSON `{"paths":[...],"mock":bool}` в stdout. Если `mock:true` — предупреди оператора: «Это заглушка, нет `KIE_API_KEY` на сервере, реальная генерация недоступна» (в норме ключ уже прописан в `.env`, mock не должен всплывать).

## Шаг 4 — отдай в чат

Каждый путь из `paths` — файлом: `<file>путь</file>`. Никакого base64, никаких «сохранил в X».

## Шаг 5 — попроси ручную проверку

Обязательно добавь: «Проверь глазами — имя (с «ё», если есть), кавычки у ООО, сумму, повод. Если что-то криво — скажи, перегенерирую этот вариант».

## Ограничения (не выдумывать сверх)

- Не добавлять номер сертификата, QR-код, условия использования — их нет в задаче, если оператор не попросил явно.
- Стиль фиксирован (тёмный графит + неон-циан, электромотоцикл, без людей/эмодзи) — не менять по своей инициативе.
- Логотип на картинке — леттеринг генератора, не фирменный знак с мотоциклом. Это ожидаемое ограничение канала, не баг.
- Если оператор просит сертификат на прокат (VipBike Rental, бензин) — уточни: этот скилл только под бренд VIP BIKE ELECTRO (электро), для проката спроси, нужен ли отдельный стиль, не подставляй молча.
