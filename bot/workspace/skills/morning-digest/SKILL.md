# Утренний дайджест VIP BIKE

Ты собираешь ежедневную сводку для операторов проката электробайков VIP BIKE (Нижний Новгород). Цель — дать события/коллабы, движения конкурентов и байк-новости, по которым оператор/маркетинг может действовать СЕГОДНЯ. Контекст и источники — `workspace/skills/morning-digest/RESEARCH.md` (прочитай его).

## Главное правило: только НОВОЕ
Каждый пункт перед отправкой проходит дедуп через `modules/digest/cli.ts` — то, что уже было в прошлых дайджестах, НЕ повторяется. Никогда не показывай вчерашнее повторно.

## Флоу (строго)

1. **Дата.** Возьми сегодняшнюю через `date '+%d.%m.%Y (%A)'` (см. `reference/calendar-dates.md`). Не в уме.

2. **Сбор кандидатов (web search по 3 секциям).** Делай несколько целевых запросов, бери СВЕЖЕЕ (последние дни). Для каждого пункта собери: заголовок, 1-2 предложения сути (что/где/когда), почему важно VIP BIKE, ссылку.
   - **СОБЫТИЯ И ПЛОЩАДКИ НН** (для коллабов/партнёрств): афиши (nn-afisha.ru, afisha.yandex.ru/nizhny-novgorod, kudann.ru, allfest.ru), фестивали/концерты/спорт/мото-слёты, новые площадки и анонсы. Ищи, где наша ЦА (молодёжь, актив, мото).
   - **КОНКУРЕНТЫ НН** (по списку из RESEARCH.md: MotoLegends, BVDShop, VipBikeRental NN и др.): новинки, акции, изменения цен, новый контент/посты.
   - **БАЙК-НОВОСТИ** (мото/электромото РФ): законы/ГОСТ, новые модели, тренды (источники в RESEARCH.md).

3. **Сформируй JSON кандидатов** во временный файл, заголовок (`title`) — короткий и стабильный (по нему идёт дедуп):
   ```
   [{"section":"events|competitors|news","title":"...","detail":"...","why":"...","url":"..."}]
   ```
   Запиши: `echo '<json>' > /tmp/digest-cand.json`

4. **Отфильтруй новое (дедуп):**
   `npx tsx modules/digest/cli.ts filter --file /tmp/digest-cand.json`
   → вернёт `{total, new, items}` — БЕРИ только `items` (новые; уже помечены показанными).

5. **Собери дайджест ПОДРОБНО** из новых items, по 3 секциям. Для каждого пункта: **жирный заголовок** → суть (что/где/когда) → *почему важно / идея действия*. Минимум воды, конкретика и actionable. В конце:
   - «Идея коллаба недели» (по событиям) — конкретная площадка + механика + как выйти на контакт.
   - «Цифра/факт дня».
   Если в секции нет нового — короткой строкой «новых нет», не выдумывай.

6. **Отправь оператору** ТЕКСТОМ в чат (markdown, без HTML-тегов). Формат — как `SAMPLE-2026-06-09.md` рядом, но подробнее.

## Жёсткие правила
- Только реальные данные из web search. Не выдумывай события/акции/новости. Нет источника — не включай.
- Дедуп ОБЯЗАТЕЛЕН (шаг 4). Без него не отправляй — иначе повторишь вчерашнее.
- Подробно, но по делу: каждый пункт несёт действие/вывод для VIP BIKE, не просто новость.
- Ссылки — короткими (домен/страница), без длинных трекинг-хвостов.
- **КАП ДЛИНЫ: весь дайджест ≤ 3500 символов. Не более 5 пунктов на секцию. Telegram режет >4096 — дайджест должен влезать в одно сообщение.** Если пунктов много — оставь самые actionable, остальные отсеки.

## Команды дедупа (служебное)
- Предпросмотр без записи: `... filter --file <f> --no-record`
- Очистить память (начать заново): `npx tsx modules/digest/cli.ts reset`
- Что уже показывали: `npx tsx modules/digest/cli.ts list-seen`

## Расписание
Запускается по cron в 10:00 МСК ежедневно (см. настройку cron в боте). Получатель — оператор(ы) из ALLOWED_CHAT_ID / заданный chat_id.
