# Чеклисты выдачи и возврата — VIP BIKE

Оператор просит чеклист — выдай нужный список ТЕКСТОМ в чат (markdown, без HTML). Полный регламент — `workspace/reference/rental-sop.md`.

## Когда срабатываю
Оператор готовится выдать или принять мотоцикл и просит порядок действий / что проверить.

## Чеклист ВЫДАЧИ

```
ВЫДАЧА БАЙКА — чеклист

Подготовка:
☐ Байк технически исправен
☐ Чистый
☐ Заряжен/заправлен на 95-100%
☐ Ключи и документы на месте
☐ Фото 8-10 со всех сторон (колёса, покрышки, пластик) + фото пробега

Клиент:
☐ Познакомиться, показать байк
☐ Проверить права и паспорт
☐ Договор оформлен (бот: prep → карточка → gen-contract) и подписан с двух сторон, с расшифровкой ФИО клиента
☐ 2 экземпляра: наш — в папку, второй — клиенту

Экипировка:
☐ Обязательно: шлем, перчатки
☐ По желанию: куртка/черепаха, второй шлем, сумка, сетка, крепление камеры, чехол, зарядка (электро)

Инструктаж:
☐ Предупредить: ПДД, запрет гонок, запрет бёрнаутов (штраф по договору)
☐ Показать крепление второго шлема (если есть)
☐ Объяснить органы управления и особенности модели
☐ Снять видео для соцсетей

После выдачи:
☐ Поставить напоминание о возврате (на дату/время конца аренды)
```

## Чеклист ВОЗВРАТА

```
ВОЗВРАТ БАЙКА — чеклист

Осмотр:
☐ Осмотреть на новые дефекты
☐ Фото пробега
☐ Фото 8-10 с тех же ракурсов, что при выдаче
☐ Проверить чистоту и сохранность экипировки

Расчёт залога (бот: команда settle):
☐ Пробег до/после → перепробег (бензин >200км, электро >150км) по тарифу из договора
☐ Сильное загрязнение → вычет за мойку
☐ Уровень топлива/заряда ниже начального → вычет разницы
☐ Дефекты → указать в Акте, подпись клиента, удержать залог до оценки (до 10 раб. дней)
☐ Нет претензий → вернуть залог

Особый случай:
☐ Ночной возврат / сильная грязь / нельзя осмотреть → возврат залога перенести на след. день после мойки при свете (фото при приёмке делать всё равно)

Завершение:
☐ Расспросить о поездке, видеоотзыв
☐ Попросить отзыв (ВК / Авито / Яндекс)
☐ Прислать онлайн-визитку, предложить подписаться
☐ Занести клиента и аренду в базу (Excel/CRM)
☐ Поставить напоминание на follow-up через 2 недели
```

## Правила
- Выдавай чеклист как обычный текст (моноширинный блок выше — копируется целиком). Без HTML.
- Если оператор спрашивает деталь (суммы штрафов, тариф перепробега) — смотри договор / `bike-prices.md`, не выдумывай.
- Расчёт залога при возврате — через команду `settle` (скилл contract-agent), не считай в уме.
