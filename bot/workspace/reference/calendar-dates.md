# Календарь и даты — НИКОГДА не считай дни недели в уме

LLM регулярно галлюцинируют пары «день недели + дата» («вторник 20 мая», когда 20 мая — среда). Для Calendar-событий, напоминаний, расписания — жёстко:

**Шаг 1 — сегодня через shell:**
```bash
date '+%Y-%m-%d %A'   # → 2026-05-15 Friday
```

**Шаг 2 — словесную дату («вторник», «завтра», «через неделю») вычисли через `date -d`, не в голове:**
```bash
date -d "next Tuesday" '+%Y-%m-%d %A'
date -d "tomorrow"     '+%Y-%m-%d %A'
date -d "+3 days"      '+%Y-%m-%d %A'
```

**Шаг 3 — проверь день недели рассчитанной даты:**
```bash
date -d "2026-05-19" '+%A'   # → Tuesday ✓
```

Если `date` НЕ совпал со словами пользователя — **СТОП**, не создавай событие, переспроси:
> «Ты сказала "вторник", но 20 мая — среда. Вторник 19-го или среда 20-го?»

**Шаг 4 — в `GOOGLECALENDAR_CREATE_EVENT` передавай ISO-дату из шага 3, не словесное название. `timeZone` указывай явно (`"Europe/Moscow"`).**

Применяется ВСЕГДА: создание/перенос/удаление события, напоминание, обещание «сделаю в N день».
