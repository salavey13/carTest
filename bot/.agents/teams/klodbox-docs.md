# Team: klodbox-docs (M4)

## Цель
Написать клиентскую документацию так чтобы нетехнический человек прошёл от README до запущенного бота не открывая код.

## Состав
- `quickstart-writer` (opus — креативный текст для клиента) — README + QUICKSTART
- `selfhost-writer` (sonnet) — docs/SELF-HOSTING + MANAGED-INSTALL + ARCHITECTURE
- `troubleshooting-writer` (sonnet) — docs/TROUBLESHOOTING + FAQ

## Порядок
Все 3 параллельно.

## Gate
1. README.md — маркетинговое описание + 1-line install
2. QUICKSTART.md — 5-минутный гайд, ~300-500 строк, скриншоты-плейсхолдеры
3. docs/SELF-HOSTING.md, MANAGED-INSTALL.md, TROUBLESHOOTING.md, FAQ.md, ARCHITECTURE.md — все созданы
4. Тестер-новичок (не разработчик) проходит QUICKSTART → бот работает
5. PRD.md M4 — все пункты ✅
