# Team: vipbot-ops (постоянная — после деплоя)

## Цель
Поддержка бота VIP BIKE в проде: мониторинг здоровья, сбор логов, авто-фикс типовых сбоев с апрувом, реестр известных проблем.

## Состав
- `error-watcher` (sonnet) — ловит ошибки в логах, готовит патч → апрув оператору/админу → применение.
- `patcher` (sonnet) — применяет одобренные точечные патчи.
- `log-collector-dev` (sonnet) — собирает/ротирует логи с VPS.
- `known-issues-curator` (sonnet) — ведёт реестр проблем/решений.

## Режим
Реактивно (на эскалацию/алерт) или по cron (`error-watcher` раз в час через `claude --print`). ⛔ Авто-фикс — ТОЛЬКО через апрув (compromise), не молча в прод.

## Gate (на каждый инцидент)
1. Root cause зафиксирован (file:line / лог).
2. Патч одобрен перед применением.
3. После фикса — smoke (бот отвечает, флоу договоров жив).
4. Запись в реестр известных проблем + `progress.md`.

## Артефакты
- Патчи в `src/`/`modules/`/`workspace/`, реестр известных проблем, логи инцидентов.
