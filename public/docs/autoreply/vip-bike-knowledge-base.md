## 1. Компания

- **VIP BIKE** — прокат и продажа мотоциклов (электро + бензин), свой мотосервис и шоурум.
- **Город:** Нижний Новгород.
- **Адрес шоурума/выдачи:** пл. Комсомольская, 2 (метро «Ленинская», центр города, GPS-точка «VIP BIKE HQ»).
- **Часы работы:** ежедневно 10:00–20:00 (МСК). Вечером выдача/возврат — до 20:00.
- **Оплата:** наличные и карта. Предоплату в чате Avito НЕ собираем, реквизиты не отправляем.
- **Бронирование:** Telegram Mini App `t.me/oneBikePlsBot` (кнопки «аренда»/«покупка» на каждый байк) или через оператора в чате.
- **Сайты:** `rental.vip-bike.ru` (каталог, аренда, прайс), `vip-bike.ru`.
- **Авито:** работаем с 2019 года, рейтинг ~4.8 — использовать для отработки недоверия.
- **Статус:** официальный дилер 79Bike (гарантия, запчасти, сервис на месте).
- **Позиционирование:** электроэндуро класса М (49 см³) — без категории А, без регистрации в ГИБДД и страховки, достаточно прав B; плюс полноценные бензиновые мотоциклы категории A и электроспортбайки.

## 3. Условия аренды

**Структура цены.** Сутки: будни дешевле, выходные дороже (+15–20%). Срок снижает ставку суток: 2–4 дня ~ −15%, 5–10 дней ~ −25%, 11–30 дней ~ −33%. Есть почасовая: 1 час и пакеты 3ч / 6ч / 12ч (пакет дешевле суммы часов). Точные ставки каждой модели — `vip-bike-rent.csv` (цена в объявлении Avito = суточная ставка будней).

**Залог.** По модели — из `deposit_rub` CSV (ориентир 15 000–50 000 ₽, точную цифру называть только по модели из CSV). Можно оставить СТС вместо наличных. Возврат — до 3 рабочих дней после возврата байка.

**Включено в стоимость.** Техосмотр перед выездом. Лимит пробега: 150 км/сутки на электро, 200 км/сутки на бензине; сверх лимита — доплата за км.

**Документы и права.**
- Паспорт + водительское удостоверение — всегда.
- Категория зависит от типа техники: бензиновые мотоциклы — **A**; дорожные электро — **B или M**; электроэндуро — права **не требуются** (класс М, 49 см³, не для дорог общего пользования).
- Категория конкретной модели — колонка `license_class` в CSV, называть по ней.
- Регистрация и страховка ТС для электро не нужны.

**Доставка.** По Нижнему Новгороду — 500 ₽. За город — по договорённости. Привозим готовым к поездке.

**Тест-драйв.** Бесплатный, по предварительной записи, ежедневно 10:00–20:00. С собой паспорт и права. Обеспечительный платёж за тест не берём.

**Экипировка — ПЛАТНАЯ, никогда не обещать бесплатно.** Шлем — 500 ₽ при почасовой аренде / 1 000 ₽ за сутки. Перчатки — 250–500 ₽. Куртки, штаны, комбинезоны — 500 ₽/сутки за предмет (в шоуруме 27 курток, 12 штанов, комбинезоны; кожа и текстиль, размеры XS–5XL, есть женские). Выдаётся на месте при получении байка.

## 4. Каталог: модели и цены — ТОЛЬКО из CSV

Каталог регенерируется скриптом `update_catalog_csvs.sh` (крон, ежедневно ~21:00 МСК) из БД. Этот файл snapshots каталога НЕ содержит — любое упоминание модели, цены, залога, характеристик в ответе клиенту обязано опираться на свежий CSV, не на память.

**`vip-bike-rent.csv` — флот аренды.** Ключевые колонки:
`make` / `model` / `year` (сопоставление с `bike_title` объявления по марке+модели), `bike_subtype` / `type` (эндуро/нейкед/спортбайк/круизер/скутер, Electric/Gas), `license_class` (категория прав), `rent_weekday` / `rent_weekend` (сутки будни/выходные), `rent_2_4d` / `rent_5_10d` / `rent_11_30d` (слои срока), `price_per_hour` / `price_per_3h` / `price_per_6h` / `price_per_12h` (почасовые пакеты), `deposit_rub` (залог), `description` / `features` (характеристики для ответа клиенту).

**`vip-bike-sale-new.csv` / `vip-bike-sale-used.csv` — продажа** (сплит по `condition`: new/used). Ключевые колонки: `sale_price` (пусто = «цена по запросу»), `original_price_rub` + `discount_percent` (скидка — аргумент для клиента), `buy_colors_json` / `buy_options_json` (цвета и опции с доплатами), остальные — как в арендном.

Правила работы с каталогом:
- Модели нет в CSV → не предлагать её и не называть цену (скрытые позиции каталога в CSV не попадают — их клиентам не предлагать).
- Цена в объявлении Avito (`item_price`) = суточная ставка будней (`rent_weekday`).
- Информации о занятости/брони в CSV нет — наличие на даты не обещать («проверю календарь, зафиксирую бронь»).

## 6. Правила ответов (кратко, детально — в промпте)

1. Только факты отсюда и из CSV (свежий снимок, не память). Нет цифры — не называть, предложить расчёт по датам.
2. Экипировка платная, тест-драйв бесплатный, скидки сверх прайса не обещать. На прямой торг — контр-якорь «могли бы и дороже», пересчёт условий (срок/часы/модель), не цены.
3. Слова-табу: «инновационный», «уникальный», «эксклюзивный», «без прав» (вместо этого — «без категории А» / «прав не требуется, класс М»).
4. В тексте объявлений: 0 эмодзи, 0 контактов, без «бесплатно/подарок/бонус» и зазывов (правила модерации Авито).
5. Наличие на даты — НЕ обещать («проверю календарь, зафиксирую бронь»), CSV цен не содержит информации о занятости.
6. Один вопрос-CTA в конце ответа. Клиент назвал срок — расчёт цифрами в том же ответе.
