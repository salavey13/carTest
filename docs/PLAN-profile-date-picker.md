# PRD: Улучшение профиля — выбор периода для зарплаты и видимость для владельца

**Версия:** 1.0  
**Дата:** 19 августа 2026  
**Статус:** К реализации

---

## 1. Проблема

**Текущее состояние:**
- Сотрудник видит свой заработок только за текущий день
- Нет возможности выбрать период и посмотреть сумму за неделю/месяц
- Владелец экипажа не видит зарплаты сотрудников в их профилях
- Нет быстрого способа узнать сколько нужно выплатить каждому сотруднику

**Боли пользователя:**
- Сотрудник хочет знать сумму заработка с 10-го или 25-го числа (даты выплат)
- Владелец хочет видеть зарплаты всех сотрудников в одном месте
- Приходится заходить в разные разделы чтобы собрать информацию

---

## 2. Пользовательские истории

### История 1: Сотрудник смотрит заработок за период
```
Как сотрудник
Я хочу выбрать диапазон дат в своём профиле
Чтобы увидеть общую сумму заработка за этот период (смены + комиссии)
```

### История 2: Владелец видит зарплаты команды
```
Как владелец экипажа
Я хочу видеть зарплаты всех сотрудников в своём профиле
Чтобы знать сколько кому выплатить на 10-е и 25-е число
```

### История 3: Владелец фильтрует по датам
```
Как владелец экипажа
Я хочу применить тот же фильтр дат к зарплатам всех сотрудников
Чтобы увидеть выплаты за конкретный период
```

## 3. Функциональные требования

### FR-1: Выбор периода в профиле сотрудника
- Добавить два поля даты: «с» и «по»
- По умолчанию: «с» = первое число текущего месяца, «по» = сегодня
- Кнопка «Применить» для обновления данных
- Отображать сумму заработка за выбранный период

### FR-2: API для расчёта заработка за период
- Эндпоинт принимает: `fromDate`, `toDate`, `memberId`
- Возвращает: смены (часы × ставка), комиссии, итоговая сумма
- Поддерживает пустой `memberId` для всех сотрудников

### FR-3: Видимость для владельца
- Если пользователь == владелец, показать блок «Зарплаты команды»
- Список сотрудников с кнопкой «Посмотреть зарплату»
- При клике — модалка с зарплатой за выбранный период
- Таблица: сотрудник | смены | комиссии | итог

## 5. Техническая реализация

### 5.1. Фронтенд (ProfileClient.tsx)
**Изменения:**
- Добавить состояние `earningsPeriod`: `{ from: string, to: string }`
- Добавить инпуты дат над блоком «Мои доходы»
- Создать модалку `TeamEarningsModal` для владельца
- Добавить условие: `if (isOwner) renderTeamEarningsBlock()`

### 5.2. API (app/api/franchize/[slug]/earnings/route.ts)
**Логика:**
```typescript
GET /api/franchize/[slug]/earnings?from=&to=&memberId=

1. Валидация дат
2. Проверка прав (crew member)
3. Запрос смен за период (crew_member_shifts)
4. Запрос комиссий за период (cash_transactions)
5. Расчёт: (hours × hourly_rate) + commissions
6. Возврат JSON
```

### 5.3. Server Actions
**Новый файл:** `app/franchize/server-actions/team-earnings.ts`
```typescript
export async function getTeamEarnings({
  slug, actorUserId, from, to
}): Promise<Array<{memberId, memberName, shifts, commissions, total}>>
```
