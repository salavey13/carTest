# План: Улучшение профиля — выбор периода для зарплаты

**Задача:** Добавить выбор диапазона дат в профиле сотрудника для подсчёта заработка + видимость зарплат для владельца

---

## Текущее состояние

**Профиль сотрудника:**
- Показывает статистику только за текущий день
- Нет выбора периода или диапазона
- Владелец не видит зарплаты сотрудников

**Что нужно:**
1. Выбор даты или диапазона (по умолчанию — сегодня)
2. Подсчёт суммы заработка за выбранный период
3. Владелец видит зарплаты всех сотрудников (с тем же фильтром дат)

---

## План реализации

### 1. Компонент выбора периода
**Файл:** `app/franchize/[slug]/profile/ProfileClient.tsx`

**Что добавить:**
```tsx
// Сверху блока заработка
<div className="flex gap-2 items-center">
  <input type="date" value={fromDate} onChange={setFromDate} />
  <span>—</span>
  <input type="date" value={toDate} onChange={setToDate} />
  <button>Применить</button>
</div>
```

**По умолчанию:**
- `fromDate`: первый день текущего месяца (10-е число если мы после 10-го)
- `toDate`: сегодня

---

### 2. Запрос данных за период
**Файл:** `app/api/franchize/[slug]/earnings/route.ts` (создать)

**Что делать:**
- Принимает `fromDate`, `toDate`, `memberId`
- Возвращает сумму заработка за период: смены + комиссии

**Логика расчёта:**
```
Если выбран период с 10.08 по 19.08:
  Суммируем все смены за этот период
  Суммируем все комиссии за этот период
  Итого = смены + комиссии
```

---

### 3. Видимость для владельца
**Файл:** `app/franchize/[slug]/profile/ProfileClient.tsx`

**Логика:**
```
Если пользователь == владелец:
  Показать список сотрудников
  Для каждого: кнопка "Посмотреть зарплату"
  При клике — открыть модалку с зарплатой за выбранный период
```

**Модалка:**
- Выбор дат (такой же как для себя)
- Таблица: сотрудник | смены | комиссии | итог

---

## Порядок работы

1. Добавить инпуты дат в `ProfileClient.tsx` (1-2 часа)
2. Создать API `/earnings` с фильтром по датам (1-2 часа)
3. Добавить видимость зарплат для владельца (2-3 часа)
4. Тестирование и полировка (1 час)
