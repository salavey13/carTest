## Критерии (по брифу босса)

Золотая ЦА = **очень похожие на vip-bike**: команда из пары владельцев + пары сотрудников,
парк ~20–80 единиц, мототехника/электро/скутеры, живой поток частных клиентов.

- **Сайт «гг»** (нет / бесплатный конструктор / старый самопис / истёкший домен) → высокий приоритет.
- **Сайт «пиздатый»** (студийный/Bitrix, всё уже умеет) → низкий приоритет: доп-приложение мало что добавит.
- **Мимо**: франшизы и сети, инструмент/оборудование (большой ассортимент), яхты/катера с капитаном
  (слишком серьёзно), прокаты приставок (поток как у компьютерных клубов), SUP и чисто летняя вода (сезонно),
  соло-одиночки с 2 единицами на Авито (с них не срубишь), гиганты 200+ единиц.

Проверка сайтов: 10 поисковых сессий + быстрое чтение 18 сайтов (сырые дампы `scripts/artmebius_out/lead_*.json`, вне репо). Грейды: **нет** = живут на Яндекс.Картах/2ГИС/VK/Авито; **гг** = tilda.ws/orgs.biz (бесплатные планы), старый самопис, сайт не открывается; **норм** = аккуратный Tilda/WordPress; **пиздатый** = Bitrix/приличный WP с каталогом и корзиной.

## Методика / воспроизводимость

1. 10 поисковых сессий: мотопрокат НН, эндуро МСК, квадро НН, скутеры НН/МСК, снегоходы НН,
   питбайки МСК/МО, электровело НН, электромото МСК, мотопрокат МО + добор URL.
   Сырые выдачи: `scripts/artmebius_out/s1..s14.json` (вне репо).
2. Быстрое чтение 18 сайтов скриптом `scripts/check_leads.py` (page_reader): платформенные
   сигнатуры (tilda/bitrix/wp/orgs.biz), размер парка из текста, франшиза, приложение.
   Дампы: `scripts/artmebius_out/lead_checks_b1..b3.json` + `lead_*.json` (вне репо).
3. Грейд сайта ставился по факту чтения; «нет» = не найден сайт ни в выдаче, ни в картах.
4. Пере-обзвон перед контактом: цены/парк меняются; у №14, №16, №20 — сначала перепроверка.
