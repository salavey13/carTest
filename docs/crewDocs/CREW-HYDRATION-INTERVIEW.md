# CREW HYDRATION INTERVIEW — «one phone call» question list
<!-- docs/crewDocs/CREW-HYDRATION-INTERVIEW.md — task168 bonus, 2026-10-30 -->

**Идея босса:** вопросы вплетаются в презентационную речь; запись одного
звонка → транскрипт → агент заполняет `franchize-hydration.sql` нового
экипажа → лендинг/каталог/контракты работают без единого ручного правка.

**Как пользоваться (агенту):**
1. Транскрибировать запись звонка (ASR, 28s slices).
2. Каждому блоку ниже соответствует СЕКЦИЯ hydration-SQL (vip-bike —
   канонический образец: `docs/crewDocs/vip-bike-franchize-hydration.sql`).
3. Ответ «не знаю / по умолчанию / как у вас» = взять значение из колонки
   «Дефолт» — экипаж всё равно запускается, а доработки вносятся потом
   через crew-admin (metadata merge, ничего не затирается).
4. Никогда не выдумывать факты: нет ответа → дефолт + пометка в шапке SQL.
5. Слог проверять через `normalizeCrewSlug` правила: `[a-z0-9-]`, lowercase.

Легенда: 🔑 = без ответа экипаж не запускается (критично); всё остальное
имеет рабочий дефолт.

## БЛОК 0 — Идентификация экипажа → `public.crews` (insert)
1. 🔑 Как называется экипаж (название брендом, как на вывеске)? — *crews.name*
2. 🔑 Какой слаг дать сайту? (предложи сам из названия; подтвердить голосом:
   «будет vip-bike.ru/<слаг> — ок?») — *crews.slug*
3. 🔑 Кто владелец: имя + ник/телефон в Telegram (его user_id ставится в
   owner_id и crew_members)? — *crews.owner_id*
4. Одной фразой: чем занимается экипаж (для описания под логотипом)?
   — *crews.description*
5. Где точка выдачи/офис: адрес или «встречаемся у метро X»? GPS если есть.
   — *crews.hq_location («56.296444, 43.946389»)*

## БЛОК 1 — Брендинг → `franchize.branding`
6. Как звучит бренд на витрине (может совпадать с названием)? — *branding.name*
7. Слоган одной строкой (что человек видит под логотипом)? — *branding.tagline*
   Дефолт: «Техника в аренду без лишних условий».
8. Есть ли логотип/фирменные фото? (если ссылка/файл — забрать; нет → ставим
   заглушку из carpix) — *branding.logoUrl / heroImageUrl*
9. Центрировать логотип в шапке? — *branding.centerLogoInHeader, дефолт true*
10. Шрифты: «как у VIP BIKE» (Archivo Black/Onest) или свои? — *branding.fonts*

## БЛОК 2 — Тема → `franchize.theme`
11. «Тёмная, светлая или обе?» (режим auto = обе с переключателем)
    — *theme.mode*
12. Три цвета голосом: «основной фон (тёмный/светлый?), акцент (золото/синий/
    красный?), цвет текста (белый/тёмный?)». Агент собирает 7 токенов палитры
    сам. — *theme.palette + palettes.dark/light*
    Дефолт: тёмная тема #0b0c10 + акцент по вкусу из ответа.

    Колесо фортуны, Карта райдеров, Стена сообщества, Прайс-калькулятор,

    (перечислить вслух — это же feature_tour флаги: то, что не выбрали,
    остаётся выключенным и включается потом чекбоксами владельца)
    — *header.menuLinks + metadata.feature_tour*

## БЛОК 5 — Страница «О нас» → `franchize.about` + contentBlocks
20. Расскажи про экипаж 3–4 предложениями (это почти готовый hero-текст).
    — *about.heroTitle/heroSubtitle*
21. Чем гордитесь: 3–6 пунктов (парк, сервис, цены, опыт…)? — *about.features / aboutCapabilities*
22. Как проходит аренда по шагам (3–5 шагов: заявка → документы → выдача →
    возврат)? — *aboutWorkSteps*
23. Частые вопросы клиентов + ответы (2–4 штуки, можно «нужно ли права
    категории A?»). — *about.faq*

## БЛОК 6 — Витрина/каталог → `franchize.catalog` + `public.cars`
24. Что в каталоге и по каким группам (байки/сервис/экипировка/запчасти)?
    — *catalog.groupOrder*
25. По каждой единице техники (rent): название, модель/год, цена сутки /
    3 дня / неделя, залог, кратко характеристики. Фото пришлёте отдельно

26. Что на продажу (sale): модель, цена, состояние (новое/б-у)? — *cars type='sale'*
27. Услуги (service): список позиций с ценой/нормо-часом? — *cars type='service', specs.service=true*
28. Бегущая строка/промо-баннеры нужны? Какой текст? — *catalog.tickerItems / promoBanners*

## БЛОК 7 — Заказ и оплата → `franchize.order` + contractDefaults
29. Самовывоз, доставка или оба? Цена доставки? — *order.deliveryModes / defaultMode*

31. 🔑 Залог стандартный и условия возврата (одной фразой для договора).
32. Включённый пробег в день и цена за превышение (для мото — да/нет)?
    — *contractDefaults.includedMileage/overageRate; дефолт 200 км / 30₽*
33. Штраф за просрочку возврата? — *lateReturnPenaltyRub, дефолт 5000₽*
34. Адрес возврата и ФИО представителя в договоре. — *returnAddress / issuerRepresentative*
35. Ориентировочная стоимость техники для пункта договора «имущество»?

## МИНИ-ШПАРИЛКА ДЛЯ РЕЧИ (порядок = порядок презентации)
«Кто вы → как назовём сайт → кто главный в TG → где выдача → слоган →
цвета → телефон/бот → про парк (по единицам: цена/залог) → продажа/сервис →
доставка/оплата/залог → пробег/штрафы → хранение → соцсети».
~15 минут разговора покрывают ВСЕ 🔑 и 80% остальных; всё недосказанное
уезжает в дефолты, помеченные в шапке сгенерированного SQL.
