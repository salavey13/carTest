## 📖 Полезные Инструкции

### 🏍️ Категории водительских прав

| Тип ТС | Категория | Где можно ездить |
|---|---|---|
| **ICE мотоциклы** (бензиновые) | Категория **A** | Только дороги общего пользования |
| **Электро мотоциклы** (кроме эндуро) | Категория **B/M** | Дороги общего пользования |
| **Электро эндуро** | **Без прав** | ❌ Нельзя на дороги и велодорожки |
| **U2 электросамокат** | **Без прав** | ✅ Велодорожки (единственный ТС в каталоге для велодорожек) |

### 📊 Расчёт стоимости аренды

Базовые цены на аренду байков можно посмотреть в CSV-файлах:
- `/public/docs/autoreply/` — прайс-листы для автоответчика
- Каталог-экспорт через скилл `catalog-csv-exporter`

**Расчёт на ходу**: посуточная цена × количество дней + оборудование.

### ✅ Проверка доступности байка

1. Получить полный список каталога (через `franchize-catalog-text` или CSV)
2. Получить список активных аренд (через `rental-ops-text`)
3. Исключить арендованные байки из каталога = доступные

### 💳 Депозиты

- Депозит хранится в `deposit_entries` (cash / Т-Банк / Сбербанк)
- Текущий баланс на руках — через скилл `deposit-tracer-text`
- При возврате байка депозит возвращается автоматически (триггер БД)

### 👥 Зарплаты

- Выплаты 10 и 25 числа каждого месяца
- Ставка: 169 ₽/час (по умолчанию)
- Вечерний дайджест через `shift-tracker-text` показывает заработок **по каждому участнику**
- `/shift` → Завершить смену → показывает `💰 Заработано: X ₽ (Y ч × 169 ₽/ч)`

## 📊 .NET Портация — Рекомендации

Для портирования на .NET (особенно для сохранения новых лидов):

### Tier 1 — В первую очередь

1. **leads-crm-text** — CRM пайплайн. **Прямо отвечает на "сохранение лидов"**. Запрашивает таблицу `franchize_intents`.
2. **rental-ops-text** — Жизненный цикл аренды: создание, продление, закрытие.
3. **shift-tracker-text** — Учёт смен + расчёт зарплаты по каждому участнику.
4. **deposit-tracer-text** — Движение депозитов (cash/банк).
5. **franchize-catalog-text** — Запрос каталога: байки, оборудование, цены.

### Tier 2 — Во вторую очередь

6. **rental-analytics-text** — Выручка, утилизация, тренды.
7. **analytics-text** — Общие дашборды.
8. **pricing-quote-text** — Движок расчёта цен.
9. **rentals-csv-exporter** — Экспорт в CSV (простой REST → CSV).

### Ключевые таблицы Supabase

```sql
-- Лиды
SELECT * FROM franchize_intents WHERE crew_id = $crewId;

-- Аренды
SELECT * FROM rentals WHERE crew_id = $crewId;

-- Смены
SELECT * FROM crew_member_shifts WHERE crew_id = $crewId;

-- Депозиты
SELECT * FROM deposit_entries WHERE rental_id IN (
  SELECT rental_id FROM rentals WHERE crew_id = $crewId
);

-- Каталог
SELECT * FROM cars WHERE crew_id = $crewId AND type IN ('bike', 'equipment', 'service');
```

Все запросы используют Supabase REST API (PostgREST) — работают одинаково из .NET через `HttpClient`.
