# Reframe: Позитивный фрейминг интерфейса (Glass Half Full)

> **Идея:** каждый «просрочено» в интерфейсе — это на самом деле возможность «доделать одну вещь и сделать аренду идеальной». Вместо подсветки того, чего НЕТ, подсвечивать то, что ЕСТЬ и что уже хорошо. Вместо давления — направление к цели. Вместо «у тебя 5 просрочек» — «5 аренд в одном шаге от идеала».

**Принципы:**
1. **Дефицит → возможность.** «Просрочено» звучит как приговор. «Осталось доделать» звучит как один шаг до победы.
2. **Проблема → путь.** Вместо «Проблемный клиент» — «Нужен контакт» или «Ждёт внимания».
3. **Пусто → готово.** Вместо «Нет задач» — «Все задачи закрыты ✓».
4. **Что есть → что должно быть.** Показывать выполненные todo, идеальные аренды, полные документы как эталон.
5. **Счётчик ≠ стыд.** Число просрочек без негативного окраса — просто данные для работы.

> **Важно:** цвет — это не наказание, а приоритет действия. Красный оставляем только там, где без действий теряются деньги (невозврат техники), всё остальное — янтарный «следующий шаг» и зелёный «всё хорошо».

## 8. Словарь замен (шпаргалка для копирайтера/агента)

| Было (дефицит) | Стало (возможность) |
|---|---|
| просрочено / просрочен | ждёт / к возврату / в фокусе / пора оформить |
| застрял / застрявшие | ждёт развития / ждёт следующего шага |
| проблемный клиент / проблемные | ждёт внимания / требует внимания |
| отсутствует / не загружен | к загрузке / в работе / до комплекта N |
| нет задач / задач нет | все задачи закрыты ✓ |
| нет активных сигналов | всё под контролем ✓ |
| продажи отсутствуют | продаж не было / день свободен |
| срочные / срочность | к делу / по приоритету / приоритет |
| задачи с просрочкой | задачи в фокусе |
| не принят | ждёт активации |
| не завершён | ждёт завершения |
| не отправлен | готов к отправке |

**Правило-тест:** если фраза звучит как обвинение («ты просрочил») — переписать как следующий шаг («осталось оформить»). Если как пустота («ничего нет») — переписать как готовность («всё закрыто») или нейтральный факт.
