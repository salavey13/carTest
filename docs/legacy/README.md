# docs/legacy — архив эпохи песочницы

Всё, что здесь лежит, — не продукт: vibe-манифесты, инсталляторы скиллов,
старые README, квесты, учебные книги, Python-эксперименты, снапшоты схемы.
Перенесено сюда из корня репозитория (`git mv`, история сохранена), чтобы
корень читался как продуктовый репо франшизы VIP Bike.

Что где:

- `README_RU.MD`, `README_RU_VIBE_HONEYPOT.md`, `SOUL.md`, `IDENTITY.md`,
  `CONSTITUTION.md`, `USER.md`, `about-me.md`, `BOOTSTRAP.md`, `START-HERE.md`,
  `AI_MAP.md`, `AGENT_ENTRY.md`, `TOOLS.md`, `autoresearch.md`, `loh.md`,
  `readme_wms.md` — манифесты/гайды vibe-эпохи
- `BOSS_*.html`, `BISS_QUEST.HTML`, `BOSS_QUEST.HTML` — квесты и протоколы
- `README4DOTERS.*`, `README_CONFIGAME.MD`, `ZAI_DOCX_INSTALLER.md`,
  `DOC_*_INSTALLER.md`, `TEST_INSTALLER.md`, `boss-mode.installer.md` —
  старые инсталляторы скиллов
- `MIGRATIONS.md` — допотопный гайд по миграциям (актуальный:
  `supabase/migrations/README.md`)
- `LICENSE`, `VIBE-LICENSE.md` — шутливая лицензия (каноническая: Apache 2.0
  в корне `LICENSE.md`)
- `claude_telegram.py`, `Configame/` — Python-эксперименты
- `books/` — учебные PDF (VPR-эпоха)
- `boss_commands_cron.md` — заметки о cron-командах босса
- `seed.sql`, `rentCarsExample.csv`, `supabase.txt` — старые сиды/снапшоты

Ничто из этого не используется кодом; удалять не стали — вдруг ностальгия ;)
